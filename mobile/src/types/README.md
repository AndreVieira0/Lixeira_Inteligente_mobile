# types

Tipagens TypeScript compartilhadas entre módulos.

- Modelos de domínio (ex.: `User`, `Bin`, `Notification`)
- Tipos de API, respostas e payloads
- Enums union types usados por mais de um módulo

Tipos específicos de um único módulo ficam junto ao módulo; aqui ficam os que são
compartilhados ou centrais ao domínio.
